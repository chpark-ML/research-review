# paper-translation

논문 본문을 **원문과 1:1 대조 가능한** 한국어 번역으로 옮긴다. 연구자가 한국어로 빠르게 읽되, 필요 시 원문을 즉시 확인할 수 있게 한다.

## 입력 / 출력

- **입력**: `papers/<slug>/_workspace/paper.txt`. 수식·기호는 원본 `assets/<file>.pdf`로 확인.
- **출력**: `papers/<slug>/translation.md`.

## 포맷 — EN/KR 문단 병렬

```markdown
# <제목> — 본문 EN/KR 병렬 번역

> 원문: <저자>. **<제목>.** <게재처>, <연도>.
> 범위: Abstract – <마지막 본문 섹션>. 부록·표·그림 캡션은 제외(본문 내 표/그림 참조는 번역에 포함).
> 포맷: 문단 단위 `**[EN]** 원문` → `**[KR]** 번역` 교차.

---

## Abstract
**[EN]** <원문 문단>
**[KR]** <번역 문단>

## §1 Introduction
**[EN]** <원문 문단>
**[KR]** <번역 문단>
...
```

## 번역 규약

1. **문단 단위 대응.** 원문 한 문단 = `[EN]` 블록 1개 + `[KR]` 블록 1개. 문단을 임의로 합치거나 쪼개지 않는다.
2. **누락 금지.** 본문 범위 내 모든 문단을 옮긴다. 건너뛴 문단이 있으면 종료 보고에 명시.
3. **전문용어 영문 유지.** 메서드명·메트릭·데이터셋·핵심 개념어(self-consistency, boosting residual, lost-in-the-middle 등)는 영문 그대로. 첫 등장 시 괄호 한국어 풀이 가능.
4. **수식.** 인라인 수식은 `$...$`, 디스플레이 수식은 `$$...$$`로 원문 기호 보존. 식 번호 `(1)`도 유지.
5. **인용 표기.** `(Author et al., 2024)` / `[12]` 형태를 원문대로 보존 (번역하지 않음).
6. **자연스러운 학술 한국어.** 직역투 지양, 의미 단위로 매끄럽게. 단 의미 추가·삭제 금지.
7. **표/그림.** 표·그림 자체는 옮기지 않되, 본문이 "Table 1 shows…"처럼 참조하면 그 문장은 번역.

## 범위 기본값

- **기본**: Abstract ~ Conclusion (본문 전체). 부록(Appendix)·References·Acknowledgements·Impact Statement는 제외.
- "부록까지" 요청 → Appendix 포함. "핵심만" → Abstract·Intro·Method·Conclusion만.
- 범위는 출력 파일 상단 `> 범위:` 줄에 항상 명시.

## 절차

1. `_workspace/paper.txt`에서 본문 범위를 식별 (Abstract 시작 ~ Conclusion 끝, References 직전).
2. 페이지 헤더(러닝 타이틀)·페이지 번호·각주 마커 등 노이즈 제거.
3. 섹션 헤더(`## §N Title`)로 구획하고 문단별 EN/KR 교차 작성.
4. 수식·기호는 원본 PDF로 교차 확인 (추출 텍스트에서 깨질 수 있음).
5. 종료 게이트 체크리스트.

## 검증 체크리스트 (종료 게이트)

```
[ ] 범위 줄(`> 범위:`)이 실제 번역 범위와 일치
[ ] 본문 범위 내 문단 누락 없음 (있으면 보고에 명시)
[ ] 각 문단이 [EN]→[KR] 쌍으로 존재
[ ] 메서드명·메트릭·개념어 영문 표기 일관
[ ] 수식·인용 표기 원문 보존
[ ] 의미 추가/삭제 없음 (요약이 아닌 번역)
```

## 트리거 예시
- "이 논문 번역해줘 / 한글 번역본 만들어"
- "번역 부록까지 / 핵심만"
- "Method 섹션만 다시 번역"
